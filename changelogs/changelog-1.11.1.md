# Borderless Window 1.11.1

*NeoForge · Fabric 1.21.1 · 2026-11-10*

> **A fix for Reese's Sodium Options users.** Screen Mode now follows F11 while Sodium's video settings are open.

## ⚠️ Important Notes

- Every setting stays as it was
- When updating, delete the 1.11.0 jar from your mods folder

## 🔧 Technical Changes

- **Fixed:** with Reese's Sodium Options installed, pressing F11 while Sodium's video settings were open changed the window but left Screen Mode showing the previous mode until the menu was reopened. It now updates right away, as it already did without that mod

## 📦 Dependencies

- Minecraft 1.21.1 with NeoForge 21.1.x, or with Fabric Loader 0.16.0 or newer
- Optional: Sodium 0.8.x on either loader, and Mod Menu on Fabric
